# ML Systems Lab Repository

Individual work. Python 3.11.8, pinned dependencies.

## Setup
```
python3.11 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Lab 1
```
bash lab01/src/run_all.sh        # Windows: run the five python commands inside lab01/src manually
```
Then fill in `lab01/report.md` and commit.

## Layout
`lab01/` ... `lab11/` each hold `report.md`, `src/`, `results/`. `project/` holds README, src, results, `data_card.md`, `model_card.md`. `data/` is git-ignored.
